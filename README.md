# Project Objective

Develop an edge-based monitoring system capable of continuously measuring environmental and electrical parameters inside commercial cold rooms while providing both local visualization and cloud connectivity for remote supervision.

---

# Challenge

Commercial refrigeration systems often operate without continuous monitoring, making it difficult to detect abnormal operating conditions before they become critical. This can lead to product spoilage, increased maintenance costs, higher energy consumption, and unexpected equipment downtime.

---

# Solution

An ESP32-based edge monitoring device was developed to continuously collect real-time data from multiple environmental and electrical sensors.

The system measures:

* Temperature
* Humidity
* Voltage
* Current

All collected data is transmitted to a cloud dashboard for remote monitoring, historical data analysis, and future analytics.

To improve on-site usability and ensure local accessibility even during network interruptions, the current temperature is simultaneously displayed on a seven-segment display.

This hybrid edge-cloud architecture provides both local visibility and remote supervision, making the solution suitable for commercial refrigeration monitoring applications.

# Results

The developed system enables continuous monitoring of commercial refrigeration equipment while providing reliable environmental and electrical measurements in real time.

By combining local visualization with cloud connectivity, the solution improves operational visibility, supports preventive maintenance strategies, reduces the risk of unexpected failures, and establishes a scalable foundation for future features such as energy analytics, anomaly detection, health scoring, and predictive maintenance.
